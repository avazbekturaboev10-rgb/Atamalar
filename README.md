# Atamalar

Yuridik atamalar lug‘ati: 8-, 9- va 10-sinf atamalari ro‘yxati, “Ma’noni topish” va “Atamani topish” testlari hamda “Moslashtirish” o‘yini.

## GitHub Pages orqali ishga tushirish

1. Ushbu fayllarni yangi GitHub repozitoriyaga yuklang.
2. **Settings → Pages** bo‘limiga kiring.
3. **Source** sifatida `Deploy from a branch`, branch: `main`, papka: `/ (root)` ni tanlang.
4. Bir necha daqiqadan keyin sayt `https://<foydalanuvchi>.github.io/<repo>/` manzilida ochiladi.

## Fayllar

- `index.html` — ilovaning o‘zi (bitta fayl)
- `favicon.svg`, `icons/`, `apple-touch-icon.png` — ikonka (oq fonda qora “A+”)
- `manifest.json` — telefonda “Bosh ekranga qo‘shish” uchun
